# L2B8 TypeScript Assignment 1

## Assignment Overview

This repository contains my solutions for **B8A1: Problem Solving with TypeScript & OOP** from Programming Hero Level 2.

The main goal of this assignment was to practice TypeScript fundamentals, problem-solving techniques, generics, and Object-Oriented Programming (OOP).

I completed 8 problem-solving tasks and wrote 2 technical blog posts based on TypeScript concepts.

## Technologies Used

- TypeScript
- Object-Oriented Programming (OOP)
- Git & GitHub

## Problem Solving (8 Problems)

All coding solutions are implemented in a single file named `solutions.ts`.

The assignment covers the following concepts:

| Problem | Topic              | Concepts Used                              |
| ------- | ------------------ | ------------------------------------------ |
| 1       | Multiply Value     | Optional Parameters, Default Values        |
| 2       | Process Input      | Union Types, Type Narrowing (`typeof`)     |
| 3       | Format Coordinate  | Readonly Tuples                            |
| 4       | Concatenate Arrays | Generics, Rest Parameters                  |
| 5       | Popular Courses    | Interfaces, Array Filtering                |
| 6       | Pluck Values       | Generics, `keyof` Constraint               |
| 7       | Employee & Manager | Classes, Inheritance, Access Modifiers     |
| 8       | Validate Age Async | Promises, Async Operations, Error Handling |
